# BAT — landing page

Static GitHub Pages site for the **BAT — Browser Automation Tool** Chrome extension.

Live at: https://sathv1kk.github.io/bat-site/

The extension source lives in the sibling repo: https://github.com/SATHv1kk/BAT

## Develop

Pure static HTML/CSS/JS, no build step. Open `index.html` in a browser.

```
index.html          the whole site (single page, inline CSS + JS)
assets/bat-icon.svg icon / favicon
```
